# Gary's Economics Github

This is an experiment to set up a part of Gary's web presence for people who want to learn more about his ideas.

Currently there are 3 Github projects

1. An LLM Chat Bot, which is composed across a few repos - some are private but we are happy to add you to the org if you want to contribute 
2. A Transcript Archive for all Gary's videos, which aspires to be a searchable knowledge-base, in a public repo.
3. A Frequently Asked Questions (FAQ) page, to which the community can contribute both Questions and Answers, in a public repo.

We also fork projects related to the Gary's Economics project to track.
